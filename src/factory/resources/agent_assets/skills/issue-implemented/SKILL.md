description: Check issue implementation against the project definition of done.
---
- Read again the issue description, and ensure everything has been properly implemented.
- Verify unit tests, integration tests, type hints, docstrings, lint, quality, and relevant documentation. 
- Fix missing items before declaring work complete.
- Ensure that every modifications has been committed and pushed
- Ensure that a PR has been opened, and that it can be merged. If not, rebase on main and fix conflicts.
- Complete the PR with proofs that the issue is ready to be closed: screenshots, CLI or tests results, and relevant documentation.
